## 0. 这份规范管什么、不管什么

**管**：不管做成什么风格都必须成立的基础功。目标是消灭最基础的失误：不该有的不对齐、细节粗糙、没有质感、笨重地一条条往下堆。

**不管**：配色、明暗、圆角大小、用什么字体、标题轻还是重、用不用阴影、动效性格。这些是风格，每次设计自己定，写进一张「风格参数表」（附录 A）。

**一条规则能写进来的标准**：换一种风格它仍然成立。符合的只有五类：

| 类型 | 意思 | 例子 |
|---|---|---|
| 一致性 | 这次设计定了一套，就只用这一套 | 间距只取自刻度；圆角只取自圆角档 |
| 关系 | 规定元素之间的相对关系，不规定具体数值 | 组内间距小于组间间距；内层圆角小于外层 |
| 下限 | 低于它就读不清、点不到 | 文字对比度、最小字号 |
| 完成度 | 该有的都做了 | 交互状态写齐、空态和出错态设计过 |
| 构图 | 画面怎么组织才不平、不堆 | 一屏一个重点；默认不加框 |

反例：「不用纯黑纯白」没有写进来。歸藏禁用纯黑纯白，Vercel 的底色就是纯白和纯黑，说明它是风格选择。58 份里找到的 15 对互相矛盾的规则都属于这一类，一律不进本规范。

**特殊风格怎么办**：某个风格确实要违反某条规则（比如刻意错位的海报风），在风格参数表的「例外」一栏写明违反哪一条、为什么。可读性下限（T-02）不接受例外。

## 1. 你点名的失误，对应哪一节

| 你说的 | 根因 | 看哪一节 |
|---|---|---|
| 不该有的不对齐 | 没有共用的对齐线；间距各写各的；容器内边距叠加 | 3 对齐、4 间距 |
| 细节不好 | 状态没写齐；形状、图标、线条不成套；极端内容没考虑 | 8 细节 |
| 质感太差 | 差别似有似无；手段太多；用占位素材；线和框比内容还重 | 9 质感、7 颜色、6 文字 |
| 笨重，一条条堆下来 | 每块都套框、都一样重、都占整行；没有重点和疏密 | 5 构图 |

带 ★ 的是红线（共 11 条），其余是基础要求。来源缩写：〔歸〕歸藏，〔V〕Vercel 官方 design.md，〔58〕58 份 DESIGN.md 的共同做法，〔底线〕ui-styles 共用底线，〔预检〕ui-preflight，〔通则〕业内通用做法，〔推断〕我根据你描述的失误补的、没有现成出处。

## 2. 开工前：先填风格参数表

| 编号 | 规则 | 怎么查 |
|---|---|---|
| P-01 | 动手画之前，先把这次设计的参数写出来：间距刻度、字号层级表、颜色角色表、圆角档、层级表、图标集。数值自己定，但必须先有。后面各节说的「刻度」「层级表」「角色」都指这张表。〔58〕 | 交付物里有这张表 |

## 3. 对齐

| 编号 | 规则 | 怎么查 |
|---|---|---|
| ★ A-01 | 每个元素的边缘或中线，必须落在本页已有的对齐线上。一页的纵向对齐线越少越好。〔V〕 | 截图上画竖线。边框造成的 1px 偏移算同一条线；右对齐、居中的元素按右边缘、中线算；除此之外，只有一个元素用的对齐线算失误 |
| ★ A-02 | 并排的单行文字按基线对齐：标题和旁边的说明、标签和值、同一行里字号不同的文字。一行里有多行内容时（比如两行的主内容配单行的标签和按钮），整体垂直居中或顶对齐选一种，全页同类的行用同一种。图标配单行文字、按钮内部，按视觉居中。〔V〕，多行的处理来自试查 | 画横线看基线；同类的行逐个比对齐方式 |
| ★ A-03 | 刻意的不对齐（错位、倾斜、出血）一页最多一处，而且它必须是这页的视觉重点。说不出理由的错位一律按失误处理。〔推断〕 | 逐个问「为什么不齐」 |
| A-04 | 同级元素完全一致：同一组卡片、行、统计块的字号、字重、内边距、内部各部分的位置都一样。不因为某一项文字更长、数值更大就单独调。〔V〕 | 同组元素叠在一起比 |
| A-05 | 数字列右对齐，用等宽数字；表头的对齐方式和它那一列一致。精度和单位写法全页一致。〔V〕〔底线〕 | 看表格每一列 |
| A-06 | 页眉、主体、页脚的内容共用一条左边线。嵌套容器不重复加同方向的内边距，避免里层内容比外层多缩一截。〔歸〕 | 画竖线看三者左边缘 |
| A-07 | 图标尺寸取自一套档位；图标和相邻文字的视觉中线对齐；图标到文字的间距全页一个值。〔通则〕 | 放大看图标和文字 |

## 4. 间距与分组

| 编号 | 规则 | 怎么查 |
|---|---|---|
| S-01 | 所有间距取自这次设计的间距刻度，不出现刻度外的值。同一种关系全页同一个值（所有卡片内边距一样、所有表单项间距一样）。〔58〕〔歸〕 | 在样式里搜间距值 |
| ★ S-02 | 亲疏分明：组内间距 < 组间间距 < 区块间距，相邻两级至少差一档（建议组间不小于组内的 2 倍）。标题离它管的内容，比离上一块内容近。〔V〕，2 倍是〔推断〕 | 量标题上下的间距 |
| S-03 | 每个间距只有一个负责的元素：由父容器统一设置，子元素不带自己的外边距。〔V〕 | 看样式里有没有两处叠加 |
| S-04 | 留白要有用途。大片空白只出现在视觉重点周围；内容没填满、栏没对齐、最后一行缺项造成的空白是失误，要重排。〔V〕 | 找出每块大空白，问它衬托了谁 |
| S-05 | 文字不贴边：文字到容器边缘、到相邻线条都留出间距（建议不小于 8px）；标题不贴住下一块内容。〔歸〕 | 放大看边缘 |

## 5. 构图：不平、不堆

| 编号 | 规则 | 怎么查 |
|---|---|---|
| ★ C-01 | 每一屏有且只有一个视觉重点。〔V〕 | 眯眼看，能不能一眼指出来；每块一样重就重排 |
| ★ C-02 | 默认不加容器。卡片、边框、底色块只在三种情况下用：可以点选或操作；需要和周围形成对比（警示、选中）；间距表达不了的真分组。不给每一段、每个指标、每一行都套框。〔V〕 | 逐个框问属于哪一种 |
| C-03 | 卡片里不套卡片；两条线不挨着出现。〔歸〕〔V〕 | 数嵌套层数 |
| C-04 | 不让同样重量的整行块从上排到底。连续的同构块（宽度、高度、结构都一样）超过 3 个时二选一：它们是真正的同级条目，就做成列表或表格，去掉每行的框；不是，就重排（分栏、分主次、合并）。〔歸〕〔V〕，3 个是〔推断〕 | 数连续同构块 |
| C-05 | 列表和表格的行只用一种分隔方式：细线、间距、隔行底色三选一，不叠加。〔歸〕 | 看行与行之间用了几种手段 |
| C-06 | 疏密有起伏：一页里有密的区域也有松的区域，不是同一种密度贯穿到底。〔歸〕〔V〕 | 缩小截图看整体 |
| C-07 | 宽度和内容匹配：说明性文字限宽（一行不超过约 36 个汉字，西文 60–75 个字符）；表格、图表这类宽内容占满可用宽度。不把短内容拉成整行，也不把宽内容挤进窄栏。〔歸〕〔V〕 | 数最长一行的字数 |
| C-08 | 层级先靠文字（字号、字重、深浅）拉开，再考虑框和颜色。一个元素身上同时用的强调手段不超过两种。〔V〕，两种是〔推断〕 | 数每个强调元素用了几种手段 |
| C-09 | 一屏内眼睛看得出的文字档位不超过 4 档（例如大标题、区块标题、正文、标签）。相邻两档的差别一眼看得出（建议字号相差 1.2 倍以上，或字重差 200 以上）；同一档里不出现两个相近的字号。〔推断〕，按档数来自试查 | 把本屏用到的字号按大小排开，看能分成几档、每档里有几个值 |
| C-10 | 一个视图一个主要操作；主按钮样式一屏只出现一次，列表里每行重复的操作除外。〔通则〕 | 数主按钮 |
| C-11 | 删除测试：逐个看框、线、图标、标签、颜色、段落，删掉后不损失信息也不影响操作的，就删。〔V〕 | 逐项过一遍 |

## 6. 文字

| 编号 | 规则 | 怎么查 |
|---|---|---|
| ★ T-01 | 字号、字重、行高只取自这次设计的层级表。字重不超过 3 种，字体族不超过 2 种（等宽字体另算）。〔58〕〔V〕 | 在样式里搜字号和字重 |
| ★ T-02 | 要读的文字对背景的对比度不低于 4.5:1，大字不低于 3:1。不接受例外。〔底线〕 | 用对比度工具量 |
| T-03 | 要读的句子不小于 12px；一眼扫过的标签、编号、时间不小于 10px（都是建议值；投屏、海报另定）。内容放不下时先改文案、再换版式，不缩字号。〔歸〕，数值是〔推断〕，分两级来自试查 | 搜最小字号，看小字是句子还是标签 |
| T-04 | 中文不用斜体；中文字距为 0，标题不用负字距；全大写、加字距这类拉丁字母的手法不套在中文上。西文字体写在前、中文字体写在后；中文和英文、数字之间留间距。〔歸〕 | 看中文标题和强调处 |
| T-05 | 行高随字号变化：字越大行高越小。中文正文行高不低于 1.5，长段落 1.7 以上。〔歸〕〔58〕 | 看层级表 |
| T-06 | 标题不出现一两个字单独成行，不在词中间断开。按钮、标签、卡片标题不折成两行；放不下就改文案或加宽。〔歸〕〔V〕〔预检〕 | 看每个标题的最后一行 |
| T-07 | 文字超长有明确处理：截断加省略号并能看到全文，或限定最多几行。不出现文字顶出容器、压住别的元素。〔预检〕 | 用最长的真实内容试 |
| T-08 | 同一个概念全页一种叫法；按钮用动词；不留占位假文案。〔歸〕 | 通读一遍文案 |

## 7. 颜色

| 编号 | 规则 | 怎么查 |
|---|---|---|
| ★ K-01 | 颜色只引用这次设计定义的角色（底色、表面、几级文字、边框、强调、状态）。组件里不直接写色值。〔底线〕〔歸〕〔V〕 | 在样式里搜色值 |
| ★ K-02 | 有颜色的地方必须有含义。强调色只表示「可以操作、已选中、需要注意」，不做装饰；同一个含义全页同一个颜色。〔58〕〔V〕 | 逐个彩色元素问它表示什么 |
| K-03 | 状态色（成功、警告、错误、信息）和强调色的含义不混用。状态不只靠颜色表达，要配文字或图标。〔V〕 | 把页面转成灰度看状态还认不认得出 |
| K-04 | 底色、表面、边框、各级文字来自同一条灰阶，色温一致，不混用冷灰和暖灰。〔58〕 | 把所有灰色排成一行看 |
| K-05 | 做深色模式时，每个颜色角色配浅色、深色两个值，两边分别量对比度。不是简单反色。〔V〕 | 两种模式各截一张图 |
| K-06 | 彩色用作小字时，用加深后的版本，保证对比度够；色块上的文字颜色单独定，不默认用白色。〔歸〕，试查里橙色、琥珀色小字的对比度只有 2.4–3.5 | 量每一处彩色文字、每一处色块上文字的对比度 |

## 8. 细节完成度

| 编号 | 规则 | 怎么查 |
|---|---|---|
| ★ D-01 | 可交互的元素状态写齐：默认、悬停、按下、键盘聚焦、禁用；需要时加上加载中、已选中、出错。键盘聚焦时有清晰可见的聚焦环。〔58〕〔V〕 | 用鼠标和 Tab 键逐个试 |
| D-02 | 形状成套：圆角只取自圆角档，同一类组件同一个圆角；边框粗细全页一个值。〔58〕 | 在样式里搜圆角和边框值 |
| D-03 | 嵌套圆角：内层圆角 = 外层圆角 − 两者之间的间距（最小为 0）。不出现里外同样大的圆角。〔通则〕 | 放大看嵌套处 |
| D-04 | 图标出自同一套：线宽、风格、尺寸档位一致。不用 emoji 当图标。〔歸〕〔V〕 | 把页面上的图标排在一起看 |
| D-05 | 层级出自一张表：同一层用同一个阴影或边框做法，光源方向一致；下拉、弹窗、提示各在哪一层写明。用不用阴影是风格的事，用了就只用表里的。〔58〕 | 对照层级表 |
| D-06 | 四种情况都设计过：没有数据、加载中、出错、内容超长。〔58〕〔预检〕 | 逐个造出来看 |
| D-07 | 图片不变形；裁切不切掉人脸、主体和关键文字；同一组图片同样的比例和处理。〔歸〕 | 看每张图的边缘 |
| D-08 | 没有浏览器默认样式漏出来：默认的蓝色链接、默认按钮、默认聚焦框。〔推断〕 | 找和整体不搭的控件 |
| D-09 | 可以点的区域不小于 24×24px，相邻的可点元素之间留间隔（WCAG 2.2 的最低要求；触屏另定）。〔通则〕 | 量最小的可点元素 |

## 9. 质感

质感不来自某一种风格。它来自四件事：**精确**（所有数值出自同一套系统）、**克制**（用的手段少）、**差别明确**（要么一样，要么明显不同）、**完成度**（该有的都做了）。前面几节已经覆盖了大部分，这一节补剩下的。

| 编号 | 规则 | 怎么查 |
|---|---|---|
| Q-01 | 差别要么没有，要么明显。两个元素要么完全一样，要么一眼能看出不同。相差 1–2px 的间距、差一点点的灰、13px 和 14px 这种看不出的字号差，都算失误。〔推断〕 | 列出页面上所有间距、字号、灰色，找相近的 |
| Q-02 | 用真实内容设计：真实长度的标题、真实数据、真实图片和图标。不用占位色块、字母圆片、假截图顶替素材。〔歸〕〔V〕，以及一版用字母圆片顶替真实素材的界面被否的教训 | 找页面上的替代品 |
| Q-03 | 轻重和内容匹配。填充色块、粗边框、粗字重、大面积底色这些「重」的手段集中给重点，其余保持轻。整页没有一处比别处重，或者处处都重，都算失误。〔推断〕 | 眯眼看哪里最黑、最浓 |
| Q-04 | 线和框比内容轻：边框、分隔线的对比度明显低于正文，不抢内容。〔歸〕〔V〕 | 眯眼看，先看到线还是先看到字 |
| Q-05 | 表面分层的方向全页一致：越上层越亮，或越上层越暗，定了就不反过来；各层之间的明度差小而均匀。〔58〕〔推断〕 | 把各层底色排在一起看 |
| Q-06 | 不拿现成的「AI 默认」凑效果：装饰用的渐变和光晕、没有含义的圆斑和几何装饰、每块都是圆角卡片加阴影、彩色图标方块、到处用胶囊标签、居中大标题下面接三张并排卡片。某个风格确实需要其中一项时，写进风格参数表并说明理由。〔V〕〔歸〕 | 对照这份清单 |

## 10. 动效

| 编号 | 规则 | 怎么查 |
|---|---|---|
| M-01 | 动效只用于三件事：说明状态变化、确认操作、保持画面连续。不为了让页面动起来而加。〔底线〕〔V〕 | 逐个动效问属于哪一件 |
| M-02 | 交互反馈 0.15–0.3 秒；系统开了「减少动态效果」时直接显示结果；不等动画也能读完内容。〔底线〕 | 打开「减少动态效果」再看 |

## 11. 交付前自查

按顺序做，每一项写结论。

1. **眯眼看**：重点是不是一眼可见（C-01）；先看到内容还是先看到线和框（Q-04）。
2. **把字模糊掉**：只看色块和位置，层级和分组还在不在。
3. **画线**：截图上画竖线和横线，查对齐线数量和基线（A-01、A-02、A-06）。
4. **删除测试**：框、线、图标、标签逐个问能不能删（C-11）。
5. **列清单**：把页面实际用到的间距、字号、字重、颜色、圆角各列一行，查有没有刻度外的值、有没有相近的值（S-01、T-01、K-01、D-02、Q-01）。
6. **真实和极端内容**：最长的标题、空数据、出错、加载中（T-07、D-06）。
