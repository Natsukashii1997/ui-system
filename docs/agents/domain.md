# 领域文档

本仓库是 single-context：术语表在根目录 `GLOSSARY.md`，架构决定在 `docs/adr/`。

- 动手探索代码前，先读这两处里和本次任务相关的部分。不存在就直接往下做，不提醒、不预先创建；用到时由 `domain-modeling` 技能（经 `grill-with-docs`、`improve-codebase-architecture` 进入）按需建。
- issue 标题、方案、测试名里提到领域概念时，用 `GLOSSARY.md` 里的叫法，不换同义词。要用的概念不在术语表里，说明要么是自己在造词，要么是真缺口，记下来交给 `domain-modeling`。
- 结论和某条 ADR 冲突时要明说，例如“和 ADR-0007 冲突，但值得重开，因为……”，不悄悄推翻。
