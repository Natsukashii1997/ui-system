# Kimi Inspired Design System

This folder contains a design system inspired by public Kimi and Moonshot AI materials reviewed on June 7, 2026. It is not the official Kimi design system. Colors, fonts, spacing, and component details are extracted or approximated from public web sources and should be treated as a practical starting point for AI-assisted UI generation.

## Files

| File | Description |
| --- | --- |
| `DESIGN.md` | Complete design system documentation using the 9-section design-md structure |
| `preview.html` | Static light/default preview of the extracted Kimi design language |
| `preview-dark.html` | Static dark-mode preview based on public Kimi dark CSS tokens |

Use `DESIGN.md` as a reference for AI agents to generate UI that feels similar to Kimi's public design language without copying proprietary assets.

## Source Notes

- Official Kimi homepage and app shell: https://www.kimi.com/
- Official Kimi K2.6 page: https://www.kimi.com/ai-models/kimi-k2-6
- Official Moonshot AI site: https://www.moonshot.cn/
- Public CSS token basis: Kimi web assets loaded from `statics.moonshot.cn` on June 7, 2026
- Confidence: high for color tokens, font stacks, sidebar/composer metrics, and dark-mode variables; medium for logo micro-accent approximations and non-visible interaction states
