# DESIGN.md 合集（59 个品牌）

> **这些不是各品牌的官方设计规范。** 它们是开源项目从各品牌公开网站（主要是营销官网）提炼出来的，有抓取错误和套模板的痕迹。单个数值不要当真，多家一致的规律才可信。

- 来源：[design.x-meng.cc](https://design.x-meng.cc/)，是 [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) 的镜像站。
- 下载日期：2026-11-20。常浩当天确认存原文（之前的规则是只记链接，见上一级 [README](../README.md) 的收录规则）。
- 许可：MIT，许可全文见本目录 [LICENSE](LICENSE)。品牌名和商标归各品牌所有。
- 内容：每个品牌 4 个文件：`DESIGN.md`（九个模块）、`README.md`、`preview.html`（浅色预览）、`preview-dark.html`（深色预览）。预览页用浏览器直接打开，字体走 Google Fonts。
- 例外：镜像站上 Warp 的 `DESIGN.md` 是空文件，这里放的是本机 `awesome-design-md` 技能里的那一份（上游版本，比镜像站新）。
- 版本：镜像站的版本比本机技能（74 份）旧。要照某个品牌的风格做页面，优先用技能；这里主要用来翻看和对比预览。本目录不跟随上游更新。
- 横向提炼：[58 份 DESIGN.md 按九模块提炼](../2026-11-20-DESIGN.md九模块提炼.md)，分模块笔记在 [design-md-notes/](../design-md-notes/)。
